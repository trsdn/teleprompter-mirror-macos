# Code of Conduct

## Principle

This project should be a factual and pleasant place for everyone — regardless
of experience, origin, gender, age, disability, religion, or identity.

## Expected

- Factual, respectful language
- Criticism of code and ideas, not people
- Patience with beginners
- Assuming good intentions in misunderstandings

## Not acceptable

- Insults, disparagement, and personal attacks
- Harassment of any kind, including through private messages
- Discriminatory or sexualized language and images
- Publication of private data of third parties without their consent

## Scope

This code applies in all project areas — issues, pull requests, commits, and
code comments — and anywhere someone publicly represents the project.

## Reporting and enforcement

Violations can be reported confidentially to the project maintainer
[@trsdn](https://github.com/trsdn). Every report is handled confidentially and
reviewed promptly.

The project maintainer may edit or remove contributions and may temporarily or
permanently exclude people from contributing in cases of repeated or severe
violations.
